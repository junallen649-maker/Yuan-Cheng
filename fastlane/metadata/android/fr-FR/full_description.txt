Une application de bureau à distance open source, l'alternative open source à TeamViewer.
Code source : https://github.com/junallen649-maker/Yuan-Cheng
Doc : https://easyreach.asia/docs/en/manual/mobile/

Pour qu'un appareil distant puisse contrôler votre appareil Android via la souris ou le toucher, vous devez autoriser Polaris à utiliser le service "Accessibilité", Polaris utilise l'API AccessibilityService pour implémenter la télécommande Addroid.

En plus du contrôle à distance, vous pouvez également transférer facilement des fichiers entre des appareils Android et des PC avec Polaris.

Vous avez le contrôle total de vos données, sans aucun souci de sécurité. Vous pouvez utiliser notre serveur de rendez-vous/relais, ou l'auto-hébergement, ou écrire votre propre serveur de rendez-vous/relais. Le serveur auto-hébergé est gratuit et open source : https://github.com/junallen649-maker/Yuan-Cheng

Veuillez télécharger et installer la version de bureau à partir de : https://easyreach.asia, vous pourrez alors accéder et contrôler votre bureau à partir de votre mobile, ou contrôler votre mobile à partir du bureau.
